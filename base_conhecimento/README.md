# Base de conhecimento do ROMUS.IA

Coloque nesta pasta os documentos que o ROMUS.IA deve consultar primeiro.

Formatos aceitos nesta primeira versão:
- PDF
- TXT
- Markdown (.md)

Fluxo da V2:
1. O ROMUS.IA procura primeiro nesta base local.
2. Se encontrar conteúdo relevante, responde somente com base nele.
3. Se não encontrar conteúdo suficiente e a pesquisa web estiver habilitada, consulta a internet por meio do Google Search Grounding do Gemini.
4. A resposta proveniente da web apresenta as fontes encontradas quando a API disponibilizar os dados de grounding.

Não coloque chaves de API nesta pasta nem no repositório.
